# React Task Manager

This project shows basic React concepts:

* Props
* State
* useState
* useEffect

---

## Features

* Add tasks
* Delete tasks
* Saves data using localStorage

---

## Concepts

**Props** – pass data between components

**State / useState** – store and update data

**useEffect** – run code when data changes (used here to save/load tasks)

---

## Run

```bash
npm install
npm run dev
```
